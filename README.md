# The Pakistan Naama

Website for The Pakistan Naama, POL 268 Group 1.

This is a single self-contained page: all the articles, team list, playlist and puzzles live inside index.html.
There is no build step and no server needed.

## View it

Open index.html in a browser, or turn on GitHub Pages for this repository
(Settings -> Pages -> Deploy from branch -> main -> / root).

## Edit the content

Open index.html, search for "const CONTENT", and edit the text there.
Each article body is a list of paragraphs. Start a paragraph with "> " to show it as a pull quote.
Text in [square brackets] shows as an orange to-do note on the page.

## Photos

Put the finalized photos in the images folder. See images/README.md for the exact file names to use.

## Deploy to Vercel

1. Import this repository at vercel.com -> Add New -> Project.
2. Leave the settings as they are and click Deploy.
